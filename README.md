Entry for the [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d)
bounty on [make.fun](https://make.fun): one line of text, the message a smart
fridge sends its owner at 3am.

> You keep opening me at 3am like the answer is in here. The answer is sleep. I am a fridge, and even I know that.

`main.ts` writes that line to `/output/entry.txt` (112 characters, one line,
UTF-8, no trailing newline). Run with Node 22.18+:

```sh
node main.ts
```
